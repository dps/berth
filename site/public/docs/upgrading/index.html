Upgrading

berth upgrade            # upgrade the way you installed it
berth upgrade --check    # just compare with the latest release

With Homebrew that's brew update then brew upgrade berth, and Berth checks the new version really got installed. The running berthd notices its new binary, waits for any deploy in progress, and restarts itself. Your apps keep running the whole time.

From a laptop, berth upgrade upgrades the laptop and then offers to do the Mac. If the two are on different versions, commands tell you.

Upgrading from 0.1.0 or 0.1.1? Run brew update && brew upgrade berth once by hand. Those versions' berth upgrade forgot the brew update.
