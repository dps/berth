What you need

  • An Apple Silicon Mac on macOS 26 or later. A Mac mini is ideal.
  • A domain on Cloudflare for public URLs (the free plan is fine). Without one, Berth still works on your LAN.
  • A GitHub account. Berth asks you to authorize it in the browser so it can clone private repos and add webhooks. Public repos work without it; Berth polls them instead.

Homebrew installs everything else: Apple's container runtime, Caddy and cloudflared.
