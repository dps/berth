AI for your apps

Berth can give any app an LLM: small models running on the Mac itself, cloud models with keys you add once, or both. Apps reach all of them through one gateway in Berth using the OpenAI or Anthropic SDK they'd use anyway, and they never see your provider keys.

Set it up once

berth ai:setup

This installs Ollama with Homebrew and starts it with the Mac (it asks first), then downloads a model that fits: qwen3:8b with 16 GB of memory or more, qwen3:4b below that. Pick another with --model gemma3:4b, or skip local models with --cloud-only. Local models run on the Mac's GPU, outside the app containers, which can't use it.

Add whichever cloud providers you want (the key prompt is hidden):

berth ai:key anthropic          # also openai, gemini, openrouter, groq, mistral
berth ai:key together --url https://api.together.xyz/v1    # anything OpenAI-compatible

Give an app access

berth ai:enable myapp

The app gets its own token and the usual variables, and redeploys:

Variable Value
OPENAI_BASE_URL http://<gateway>:7790/v1
OPENAI_API_KEY berth_ai_… (this app's token)
ANTHROPIC_BASE_URL http://<gateway>:7790/anthropic
ANTHROPIC_API_KEY the same token

The official SDKs read those by themselves, so there's nothing Berth-specific in your code:

import OpenAI from "openai";
const client = new OpenAI();   // reads OPENAI_BASE_URL and OPENAI_API_KEY
const reply = await client.chat.completions.create({
  model: "default",
  messages: [{ role: "user", content: "Hello!" }],
});

Python's openai and anthropic packages work the same way. Every provider speaks the OpenAI format (/v1/chat/completions, /v1/embeddings, /v1/models), and Claude models also speak Anthropic's own API, for tools, prompt caching and extended thinking.

Choosing models

Apps ask for a model by name, like local/qwen3:8b or anthropic/claude-sonnet-5-5, or by an alias you set up once for every app:

berth ai:alias smart anthropic/claude-sonnet-5-5
berth ai:alias fast  groq/llama-3.3-70b-versatile
berth ai:models                  # aliases, local models, providers
berth ai:pull nomic-embed-text   # another local model, e.g. for embeddings

ai:setup points default at the local model. I'd write apps against aliases ("default", "smart") rather than model names: change what an alias points at and every app picks it up immediately, no redeploy.

Limits and usage

berth ai:enable myapp --models default,smart --monthly-tokens 2000000 --rpm 60
berth ai:usage                   # requests and tokens per app and model this month
berth ai:status                  # what's running, what's loaded, each app's usage
berth ai:disable myapp           # revoke its token

--models takes aliases, provider/model or provider/*. An app over a limit gets a 429 that says which limit and how to raise it. Usage records tokens and timings, never prompts or replies.

Dev versions of an AI app get their own token that only reaches local models, so an agent testing changes can't run up a cloud bill (berth ai:enable myapp-dev --models 'local/*,smart' lifts that).

Memory

A loaded local model takes real memory: about 5 GB for an 8B model, 2.5 GB for a 4B one. Ollama lets go of it after 5 idle minutes. berth status shows what's loaded, counts it, and warns when apps, databases and the model together get close to the Mac's RAM. On an 8 GB Mac, use a cloud provider (or a really small model).

Looking inside a model

Ollama only answers. berth ai:mlx runs a second local model, with MLX on the GPU, whose insides apps can read and change: Qwen3 8B in 4 bits unless you name another MLX model (berth ai:mlx mlx-community/Qwen3-4B-4bit). It sets up its own Python with uv (offering brew install uv), downloads the model once (about 5 GB) and runs it as mlx/Qwen3-8B-4bit, through the same gateway, token and limits as any model. It loads on first use and lets go of its memory after 15 idle minutes.

Two things only this model does:

# Which MLP neuron fires for a concept, and not for related ones?
curl "$OPENAI_BASE_URL/interp/contrast" -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{"model":"mlx/Qwen3-8B-4bit","target":"San Francisco","others":["Oakland","Seattle","Paris","..."]}'

# Chat with a concept turned up. A steer entry adds the concept's direction
# (its activations less its neighbours') to one layer, or pins one neuron.
curl "$OPENAI_BASE_URL/chat/completions" -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{"model":"mlx/Qwen3-8B-4bit","messages":[{"role":"user","content":"Plan my weekend"}],
       "steer":[{"layer":12,"target":"San Francisco","others":["Oakland","..."],"scale":3}],
       "frequency_penalty":1}'

POST $OPENAI_BASE_URL/interp/trace runs text (or messages) through once and answers token by token: the neurons you name, how close each token's residual stream is to a concept's direction (directions, as cosines), and with top set, each layer's strongest neurons. It takes steer too, to see what a steered model sees. More, when asked:

  • "map": true: every neuron in the model as one byte per token, pooled to fit; "map_token": 5 for every neuron at one token, or "max" for each neuron's peak over the text.
  • "lens": 3: the logit lens, each layer's residual stream read through the final norm and output head, as the three likeliest next tokens per token.
  • "attention": {"layer": 12, "head": 3}: where each token looked in that layer, as bytes (head -1 averages the heads).

Two more routes:

  • POST $OPENAI_BASE_URL/interp/scan with texts (up to 512) and neurons runs them all in batches and returns each neuron's strongest examples, token by token: a page of what a neuron is for.
  • POST $OPENAI_BASE_URL/interp/patch does causal tracing. Give it a clean prompt ("The Eiffel Tower is in the city of") and a corrupt one with the subject swapped, the same number of tokens long (or a list to try in turn), and a site (stream, mlp or attn). It reruns the corrupted prompt once per layer and token with just that activation copied from the clean run, and answers with the clean answer's probability for each.

The contrast answers with the best neurons, each with its layer, index, score and how hard it fired for every concept, and what it says: the words its output weights raise most, with says_z, how far the top one stands out from the rest of the vocabulary. Most neurons sit around 5; past 8 a neuron writes that word, and pinned high, the model just repeats it. Add "depth": [0.25, 0.65] to search only the middle of the model, where ideas form rather than spellings or next words, and "writers": false to leave writers out. Scan answers carry says too. A steer entry is either {layer, target, others, scale} or {layer, neuron, value}. Directions steer well around a third of the way through the model, at a scale of 2 to 3; past that the model tends to say only the concept. One neuron, even the one that best picks the concept out, rarely changes what the model says before it breaks it. Pin it in units of its peak over many texts (scan finds it); several of a concept's middle-layer neurons pinned together, at a few times their peaks, can steer where any one of them can't.

The gateway listens on port 7790 on the containers' network, and only containers on this Mac can reach it. To change the port, set ai_port in ~/.berth/config.json and run berth reload. To use Ollama on another machine, set ollama_url in ~/.berth/ai/config.json.
